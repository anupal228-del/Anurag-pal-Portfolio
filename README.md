# Anurag Pal — Hybrid Creative Portfolio

A hybrid creative portfolio combining editorial typography, cinematic imagery, experimental details and a clear professional structure.

## Design direction
- Warm editorial typography paired with a dark cinematic work section.
- Acid-lime and warm-red accents used selectively.
- Asymmetric hero composition, portrait treatment and moving marquee.
- Large project/brand visual and clickable QR project cards.
- Clean About, Capabilities, Experience, Education and Contact sections.
- Responsive mobile navigation, scroll reveals and accessible QR modal.

## Files
- `index.html` — page content
- `style.css` — visual design and responsive layout
- `script.js` — navigation, reveal animations, cursor and QR modals
- `assets/anurag-portrait.jpg` — portrait extracted from supplied portfolio PDF
- `assets/work/` — brand visuals extracted from supplied PDF
- `assets/qr/` — original QR artwork extracted from supplied PDF

## Publish with GitHub Pages
1. Create a new public repository on GitHub.
2. Extract this ZIP and upload the **contents** of this folder to the repository root.
3. Confirm `index.html` is at the root and the `assets` folder is alongside it.
4. Commit the files.
5. Open Settings → Pages.
6. Choose `Deploy from a branch`, branch `main`, folder `/(root)`, then Save.
7. Wait for the GitHub Pages deployment to finish.

No build tools or package installation are required.
